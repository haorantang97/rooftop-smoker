# 任务二：给「抽根烟」另外三套天台风景做高细节 3D 模型（北海道、旷野、纽约）

## 背景
- 和上一份任务书 `docs/inaka-modeling-brief.md` 同一个项目、同一套做法、同一套约定。上一份你做得很好（`scripts/blender/inaka*.py`、`web/public/vista-models/inaka/`），**请沿用你的 `inaka_core.py` 工具和画风**。
- 楼顶本身是像素风；楼下风景要细腻、和谐、有光影和配色美感。不要纪念碑式的夸张地标、不要粗糙方块。
- 参考图：用项目 `.env` 里的 `GEMINI_API_KEY`（和上次一样，用户已同意），不要把 key 打印出来或写进任何文件。参考图存 `docs/vista-refs/<风景>/<模型名>.png`。

## 做法（同上次）
1. 每个模型先生成 1–2 张参考图（统一画风、3/4 视角、纯色背景）。
2. 照参考图在 Blender 里用 Python 程序化建模，脚本放 `scripts/blender/`（比如 `hokkaido.py`、`wilds.py`、`nyc.py`，可以 import 你的 `inaka_core.py`）。
3. 每个模型渲染预览图到 `.tmp/previews/<风景>/<模型名>.png`，自己对照参考图检查，不像就改。

## 模型清单

### A. 北海道（冬天的海边小镇，雪很厚）→ `web/public/vista-models/hokkaido/`
- `house_red` `house_blue` `house_green`：北海道式两层木板房（外墙横向雨淋板 / 镀锌板），彩色铁皮人字顶（红 / 蓝 / 绿），屋顶上盖着厚厚一层雪（雪是模型的一部分，白色顶点色，边缘圆润、檐口垂一点雪檐），二楼窗户，**玄关外加一个封闭的玻璃风除室**，房侧**灯油罐（白色或绿色的卧式小油罐，架在铁架上）**，细铁皮烟囱，窗户和风除室用 `glow` 材质。约 12×9 米。
- `house_flat`：北海道的「无落雪」平顶 / M 形屋顶两层房（方正、浅色外墙、屋顶边缘积雪），同样有风除室和灯油罐。
- `barn`：红色复斜屋顶（gambrel）的大谷仓，白色门框，屋顶积雪；旁边连一个圆筒筒仓（silo，带圆顶，雪盖）。
- `station`：无人小车站：小木站房（候车室窗户 glow）、短站台、站名牌（不写真实站名，空白或抽象符号）、站台灯。
- `train`：单厢柴油车（白色车身、绿色或黄色腰线，**不画任何真实公司标志**），车窗用 `glow`（夜里亮），车头两盏灯 `glow`，长约 21 米，车顶积一点雪。
- `crossing`：铁路道口：一根带两盏红灯、黄黑叉形牌的立柱 + 黄黑栏杆（栏杆单独做成一个子部件也可以，游戏里会让它抬起落下；如果不方便就整体导出，栏杆水平放下状态）。
- `pole`：北海道的木 / 水泥电线杆（横担、瓷瓶、顶上一小撮雪），`pole_lamp`：带路灯的款（灯罩 `glow`）。
- `boat`：港里泊着的白色小渔船（驾驶舱、桅杆、船舷上一点雪）。
- `lighthouse`：防波堤尽头的红白小灯塔（约 12 米，顶上灯室 `glow`）。
- 树：`todomatsu`（压满雪的冷杉，一层层枝条上积雪）、`birch`（落了叶的白桦，白树皮黑斑）、`larch`（落了叶的落叶松，细枝灰褐）；每种再出 `_lo` 低面数版。
- `vending_snow`：落了雪的自动贩卖机（可以复用 inaka 的贩卖机加雪）。

### B. 旷野（美国西南部那种高原荒漠、红色平顶山，夜里看银河）→ `web/public/vista-models/wilds/`
- `windmill`：老式多叶片风车水泵（铁架塔、18 片叶轮、尾舵），**叶轮单独做成一个子物体并命名为 `wheel`**（游戏里要让它转），塔高约 10 米。
- `trough`：圆形镀锌饮水槽 + 一个小储水罐。
- `pickup`：一辆废弃的老皮卡（圆润车头、锈红褪色漆、没有轮胎的一侧略塌），不要任何真实品牌标志。
- `shed`：小木板棚 / 牧场工具房（旧木板、锈铁皮顶）。
- `fence`：一段木桩铁丝围栏（4 根歪斜木桩 + 3 道铁丝，约 12 米长，首尾能接起来）。
- `mailbox`：路边的老式邮箱（木桩上一个圆顶铁皮箱）。
- 植物：`juniper`（低矮虬曲的刺柏，2 个变体 `juniper` `juniper_b`）、`sage`（一丛灰绿色鼠尾草，0.6–1 米）、`yucca`（丝兰，一丛尖叶 + 高花茎）、`cholla`（仙人掌一丛）；每种再出 `_lo`。
- 石头：`boulder_a` `boulder_b` `boulder_c`（风化的红砂岩大石，带分层纹理的顶点色，1–4 米）。

### C. 纽约（俯瞰曼哈顿中城，夜里灯火通明）→ `web/public/vista-models/nyc/`
普通楼群游戏里自己程序化生成，这次只做「地标」和屋顶小物：
- `deco_tower`：阶梯式装饰艺术摩天楼（逐级退台、顶部系泊杆尖顶，**仿那种气质但不要照抄任何真实建筑**），约 380 米高（不含尖顶），窗户做成 `glow` 竖条，顶部几级退台夜里打金色泛光（也用 `glow`）。
- `crown_tower`：钢冠尖塔（顶部是层层叠叠的拱形钢冠 + 三角窗 + 细针尖），约 320 米，冠部三角窗 `glow`。
- `supertall`：现代超高层（方底、往上扭转收成八角、顶部细长天线），约 540 米含天线，玻璃幕墙。
- `slant_tower`：顶部 45° 斜切的办公楼（斜面夜里整面发白光 `glow`），约 280 米。
- `pencil_tower`：细高的住宅「铅笔楼」，约 430 米，方格大窗。
- `pyramid_tower`：老式金字塔尖顶的装饰艺术塔楼（铜绿尖顶，夜里尖顶金色 `glow`），约 250 米。
- `bridge_tower_stone` `bridge_tower_steel`：悬索桥的桥塔（石砌哥特尖拱双门洞 / 钢结构），塔高约 90 米、宽约 40 米（主缆和桥面游戏里自己画，你只做塔）。
- `water_tower`：老纽约屋顶木水箱（木桶、钢箍、锥顶、钢架腿和爬梯）。
- `rooftop_set`：屋顶设备一组（空调外机、通风帽、电梯机房小屋），约 15×10 米。
- 尺度提示：楼的模型可以按真实尺寸建，面数靠「重复的窗格用少量几何 + glow 条」控制。

## 必须遵守的约定（和上次一样，游戏代码依赖）
- 只导出上面列出的文件名，放到对应文件夹。
- Blender Z 朝上、正面朝 -Y、单位米、底部落在 z=0、原点在底面中心，导出 `export_yup=True`。
- 材质只用 `body`（顶点颜色 `Color`，`export_vertex_color='ACTIVE'`）和 `glow`（夜里发光的部分）。**不要用贴图**。树叶用绿色系顶点颜色（`g > 1.1r && g > b`）；**雪用接近白色的顶点颜色**。
- 面数预算：北海道房子 ≤ 3 万、谷仓 ≤ 2 万、火车 ≤ 2 万、细节树 ≤ 1.2 万、`_lo` ≤ 1500、小物 ≤ 5000；旷野风车 ≤ 1.5 万、皮卡 ≤ 1.5 万、植物 ≤ 4000（`_lo` ≤ 600）、石头 ≤ 3000；纽约地标楼每栋 ≤ 6 万、桥塔 ≤ 2 万、水箱 ≤ 3000、屋顶设备 ≤ 5000。
