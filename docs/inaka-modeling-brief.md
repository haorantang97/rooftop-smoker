# 任务：给「抽根烟」的「夏日乡间」天台风景做高细节 3D 模型

## 背景
- 项目在 `/Volumes/Vault/Data/Projects/smoke-break`（Three.js r170 + Vite 网页游戏）。玩家站在一栋两层小楼的楼顶，远眺一片日本乡下的山谷（夏天、稻田、老屋、里山、积雨云）。
- 楼顶本身是像素风；**楼下风景要的是另一种风格：细腻、温馨、和谐，有光影和配色的美感**（盛夏的蓝天白云、油绿的田、夕阳西下）。不要纪念碑式的地标，不要粗糙的方块低多边形。
- 现有的程序化建模脚本：`scripts/blender/inaka.py`（Blender 5.2 Python，后台运行），已经能出一版模型到 `web/public/vista-models/inaka/*.glb`，预览图在 `.tmp/previews/`。你的任务是把这些模型做得**细节丰富得多**。

## 做法（请按顺序）
1. **先生成参考图**：用你的图片生成能力，为下面每个模型各生成 1–2 张参考图（统一画风：温暖细腻的日本乡间夏日，略带插画感但造型写实；正面偏 3/4 视角，纯色背景，方便照着建模）。图片存到 `docs/inaka-refs/<模型名>.png`。
2. **照着参考图在 Blender 里复原**：改写或扩展 `scripts/blender/inaka.py`（可以拆成多个文件放在 `scripts/blender/`），用 Python 程序化建模，尽量还原参考图里的细节：
   - 民房（4 种：灰瓦入母屋、红褐石州瓦、深蓝瓦、茅草顶）：瓦片一片片的层次、屋檐的弧度和椽子、木格拉门（障子 / 雨户）、檐廊、玄关、雨樋、基石、外墙的木板和白灰、小庭院的盆栽、石灯笼、晾衣架。
   - 土仓、铁皮农具棚、水泥电线杆（横担、瓷瓶、变压器、路灯款）、自动贩卖机（3 色）、路口的橙色反射镜、乡下公交站、小神社（红鸟居、祠、石灯笼）。
   - 树：榉树、橡树、枫树（阔叶，叶团要细碎，不要大块多边形）、杉树、竹丛、向日葵；每种树再出一个低面数版本（文件名加 `_lo`），给远处成百上千棵用。
3. 每个模型渲染一张预览图到 `.tmp/previews/<模型名>.png`（Workbench 或 EEVEE 都行），自己对照参考图检查，不像就再改。

## 必须遵守的约定（游戏代码依赖这些，不能变）
- 导出 `.glb` 到 `web/public/vista-models/inaka/`，**文件名保持不变**：`minka_gray minka_sekishu minka_navy minka_thatch kura shed_blue shed_red pole pole_tr pole_lamp vending_red vending_blue vending_white mirror busstop shrine tree_keyaki tree_oak tree_maple tree_cedar bamboo sunflower tree_keyaki_lo tree_oak_lo tree_cedar_lo`。
- Blender 里 Z 朝上、模型正面朝 -Y、单位米、底部落在 z=0、原点在底面中心（导出用 `export_yup=True`）。尺寸参考现有脚本（民房约 9–12 米宽）。
- 材质只用两种：`body`（颜色写在顶点颜色属性 `Color` 里，导出 `export_vertex_color='ACTIVE'`）和 `glow`（窗户、贩卖机灯箱、路灯灯罩：游戏夜里让它发光）。**不要用贴图**。树叶部分用绿色系顶点颜色（游戏靠「绿色明显大于红、蓝」认出叶子来做软光和风吹摆动）。
- 面数预算：每栋房子 ≤ 3 万三角面；细节树 ≤ 1.5 万；`_lo` 树 ≤ 1500；电线杆、贩卖机等小物 ≤ 5000。
- 跑法：`/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P scripts/blender/inaka.py -- web/public/vista-models/inaka .tmp/previews`

## 不要做的事
- 不要改 `web/src/`、`server.js`、`public/` 下的任何代码（同一个文件夹里还有别的会话在改游戏代码）。
- 不要 git 提交、不要切分支。
- 临时文件放项目的 `.tmp/`。
