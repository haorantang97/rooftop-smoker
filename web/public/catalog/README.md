## 三、全量自检结果

1. **JSON 解析与 ID 一致性**：`cigarettes.json`（95 条）、`drinks.json`（35 条）、`snacks.json`（45 条）均通过 `JSON.parse` 校验；全部 175 个 `id` 保持不变且全局唯一；所有 `images` 引用文件 100% 存在且无任何多余目录或临时文件。
2. **图片像素规格**：
   - 95 张 `cig/<id>/front.png` 全部校验为 **`512 × 768`** PNG；
   - 35 张 `drink/<id>/label.png` 全部校验为 **`1024 × 512`** PNG（主视觉居中、左右边缘无缝衔接）；
   - 45 张 `snack/<id>/front.png` 全部校验为 **`512 × 640`** PNG。
3. **字段命名规范**：
   - 香烟 `name` / `name_en` 均为纯规格描述（如「红色硬盒」「朱红描金软包」「冰蓝渐变爆珠超细支」）；
   - 饮料与零食 `name` 均为纯种类与口味描述，且每条均包含严格 **2–4 个汉字**的 `type_zh` 字段；
   - 真实品牌名仅保留在 `inspiration` 字段供内部核对，非 `inspiration` 字段零真实品牌名残留。
4. **目录隔离**：所有文件写入与覆盖操作均严格限定在 `web/public/catalog/` 内，未改动项目其他任何文件。
